# Client onboarding

Admin uses **Site Admin** only. Zone Safety / Vehicle / Face are not required to operate a live site.

1. Installer places the mini-PC and opens Site Admin.
2. **Wizard:** site name, type, timezone.
3. **Cameras:** add RTSP (Test until green) and/or upload a drill video.
4. **Rules:** pick camera, scan type, draw ROI if needed, channels.
5. **Monitor:** pick the same camera → **Watch live** — all rule ROIs and detections play on the video (verify before go-live).
6. **Settings:** WhatsApp numbers, optional admin PIN, Viewer vs Admin on this browser.
7. **Wizard → Start scanning (Go live).**
8. Daily: **Alerts** and **Reports** (CSV export). Change cameras/rules only when the site changes.

**Roles:** Admin = full Site Admin. Viewer = Alerts + Reports + Monitor (watch only).
