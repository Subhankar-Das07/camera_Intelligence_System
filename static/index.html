Camera Intelligence System

One product shell for zone safety analytics, vehicle plate recognition, and face identity management. Use the top navigation to open a feature workspace. Each feature keeps its own UI folder so developers can own a branch.

How to use

  • Pick a feature from the top bar — you stay inside the same product chrome.
  • On each page, read the Guidance panel for short setup notes.
  • Connect a video file or RTSP camera, then run that feature’s pipeline.
  • Structured data (vehicles, faces, sessions) is stored in Redis.

Developer note — branch ownership

Keep feature work isolated under one folder so merges stay clean:

  • static/features/zone-safety/ — intrusion / danger zone / fall UI
  • static/features/vehicle/ — vehicle UI
  • static/features/face/ — face UI
  • static/shell/ + static/shared/ — shared chrome only
